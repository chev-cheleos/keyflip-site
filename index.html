KeyFlip

Support · Поддержка

English

KeyFlip is a menu-bar utility for macOS that notices when a word was typed in the wrong keyboard layout and corrects it as you type — for example ghbdtn becomes привет. Everything happens on your Mac. Nothing is sent anywhere.

Requirements

  • macOS 13 or later
  • Two permissions, both granted by you in System Settings → Privacy & Security: Accessibility and Input Monitoring. KeyFlip cannot see any typing until both are enabled.

Getting started

  • Open the KeyFlip menu-bar icon and choose Permissions…, then enable KeyFlip in both lists. Relaunch KeyFlip if macOS asks.
  • Type normally. When a word comes out in the wrong layout, KeyFlip rewrites it and switches the input source to match.
  • To force a conversion by hand, hold Control and double-click a word.
  • If a correction was wrong, delete it and retype — KeyFlip leaves that word alone for the next few minutes.

Common questions

Nothing happens when I type. Almost always a missing permission. Check both Accessibility and Input Monitoring, then quit and reopen KeyFlip.

It corrected something it should not have. Delete the correction and retype the word. To make it permanent, add a rule under Settings → User Dictionary.

Does it read my passwords? No. Secure text fields and Secure Event Input are ignored, and the app has no networking code at all.

Русский

KeyFlip — утилита для macOS в строке меню. Она замечает, что слово набрано не в той раскладке, и исправляет его прямо во время набора: например, ghbdtn превращается в привет. Всё происходит локально на вашем Mac, никакие данные никуда не отправляются.

Требования

  • macOS 13 или новее
  • Два разрешения, которые вы выдаёте сами в Системных настройках → Конфиденциальность и безопасность: Универсальный доступ и Мониторинг ввода. Без них KeyFlip не видит набор текста.

Начало работы

  • Откройте значок KeyFlip в строке меню, выберите Разрешения… и включите KeyFlip в обоих списках. Перезапустите приложение, если macOS попросит.
  • Печатайте как обычно. Если слово вышло не в той раскладке, KeyFlip перепишет его и переключит источник ввода.
  • Чтобы преобразовать слово вручную, удерживайте Control и дважды щёлкните по нему.
  • Если исправление было лишним — удалите его и наберите слово заново. Несколько минут KeyFlip не будет трогать это слово.

Частые вопросы

Ничего не происходит при наборе. Почти всегда дело в разрешениях. Проверьте оба пункта и перезапустите KeyFlip.

Исправило то, что не нужно. Удалите исправление и наберите слово заново. Чтобы закрепить это, добавьте правило в Настройках → Пользовательский словарь.

Читает ли приложение пароли? Нет. Защищённые поля и Secure Event Input игнорируются, а сетевого кода в приложении нет вообще.
